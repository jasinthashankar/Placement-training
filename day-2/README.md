## interview based questions
Q1. What is the difference between = and ==?
= is used to assign a value to a variable, whereas == is used to compare two values.

Q2. What does % return?
% returns the remainder after division

Q3. What are the three logical operators in Python?
and → both conditions must be true
or  → at least one condition must be true
not → reverses the condition

Q4. What is the purpose of elif?
elif is used to check another condition when the previous condition is false.

Q5. What is indentation in Python?
Indentation is the whitespace at the beginning of a line that Python uses to define a block of code.

Q6. Why do we use int(input()) instead of just input() when taking an integer?
input() returns the user's input as a string by default. int() converts that string into an integer.

Q7. and
and returns true only when both conditions are true

Q8. or
or returns true when at least one of the conditions is true.

Q9. if vs elif
if checks the first condition. elif checks another condition when the previous condition is false.
